# hagane

※　このプロジェクトは開発中です。

`hagane`はModern C++ (C++26)で記述されたVulkanをラップするライブラリです。

### 目的

`Vulkan`のCスタイルの記述が他の開発において著しく支障を来したため、C++スタイルであり型安全なラッパーを定義しようと考え、開発に取り組みました。

### haganeの特徴

1. **必要最小限の構成**: 今後紹介する`sui`で用いられる実用的な構造体、関数のみのラップを行っています。このため、広大な`Vulkan`の仕様を探索しなくても良い設計となっております。
2. **エラーハンドリング**: `std::expected`等を用いたエラーハンドリングを行い、例外を使用していません。`VulkanHPP`では基本的に例外を使用するため、ユーザーの`-fno-exceptions`指定が妨げられることを考慮しました。
3. **C++的記述**: オブジェクト指向での記述につとめ、列挙体をスコープ付き列挙体として定義するなどを行っています。
4. **定義動作の保証**: `#pragma once`を除き、基本的に純粋なC++規格を遵守します。厳密エイリアシング規則s等に関する問題も発生しません。
